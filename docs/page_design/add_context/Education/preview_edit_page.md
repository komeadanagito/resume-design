# Page 1 预览编辑页：Education 教育

## 页面状态

- 触发路径：点击 `Add Content 添加内容` 后，选择 `Education 教育`
- 当前界面：预览编辑页 / Edit Entry 编辑条目
- 编辑对象：Education / 教育经历
- 页面用途：新增或编辑简历中的学位、学校、起止时间、地点和教育经历描述
- 布局：上方编辑卡片 + 下方固定确认区域
- 主色：深紫色标题文字，紫色工具栏选中态，粉色渐变确认按钮
- 语言：中英双语

## 编辑卡片

- 样式：白色大圆角卡片，轻微阴影
- 背景：页面底色为浅米灰色
- 卡片内部包含：
  - 标题区
  - 教育基础信息表单
  - Description 描述富文本编辑器
  - AI 辅助操作区

## 顶部区域

- 页面标题：Edit Entry 编辑条目
  - 位置：左上
  - 样式：大号深紫色粗体
- 提示入口：Get 得到Tips 尖端
  - 位置：右上偏中
  - 图标：灯泡
  - 样式：深色文字
- 预览按钮：
  - 位置：右上
  - 图标：眼睛
  - 样式：浅灰圆角图标按钮
- 删除按钮：
  - 位置：预览按钮右侧
  - 图标：垃圾桶
  - 样式：浅灰圆角图标按钮

## 表单字段

### Degree 程度

- 标签：Degree 程度
- 输入框占位文案：Enter Degree / Field Of Study / Exchange Semester
- 样式：浅灰色圆角输入框

### School 学校

- 标签：School 学校
- 输入框占位文案：Enter school / university
- 样式：浅灰色圆角输入框
- 右侧按钮：
  - 文案：Link 关联
  - 图标：链条
  - 样式：白色描边圆角按钮
  - 用途：添加学校或教育经历相关链接

### Start Date 开始日期

- 标签：Start Date 开始日期
- 输入框占位文案：MM/YYYY
- 样式：浅灰色圆角输入框

### End Date 结束日期

- 标签：End Date 结束日期
- 输入框占位文案：MM/YYYY
- 样式：浅灰色圆角输入框

### Location 地点

- 标签：Location 地点
- 输入框占位文案：City, Country
- 样式：浅灰色圆角输入框

### Description 描述

- 标签：Description 描述
- 输入类型：富文本编辑器
- 占位文案：
  - Add a description of your education entry...
  - 请添加教育经历描述......
- 编辑区域样式：
  - 浅灰色背景
  - 圆角矩形
  - 顶部工具栏与正文区域之间有分割线
  - 正文区域高度较大，适合输入教育经历、课程、荣誉或交换经历描述
