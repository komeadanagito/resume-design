# Page 1 点击预览：个人信息卡片

## 页面状态

- 触发方式：点击个人信息卡片 / 个人信息卡片编辑按钮
- 页面名称：个人信息卡片点击预览
- 当前界面：Edit Personal Details 编辑个人信息面板
- 布局：表单编辑页，左侧为主要输入字段，右侧为头像上传区域
- 底部操作区：固定底部确认栏
- 主色：深紫色标题文字，粉色渐变确认按钮

## 顶部区域

- 标题：Edit Personal Details
  - 位置：左上
  - 样式：大号深紫色粗体
- 提示入口：Get Tips
  - 位置：右上
  - 图标：灯泡
  - 样式：深色文字

## 基础信息字段

### Full name

- 标签：Full name
- 输入框占位文案：Enter your title, first- and last name
- 样式：浅灰色圆角输入框

### Professional title

- 标签：Professional title
- 输入框占位文案：Target position or current role
- 样式：浅灰色圆角输入框

### Photo

- 标签：Photo
- 位置：右侧
- 头像占位：
  - 形状：大号浅灰圆形
  - 图标：白色相机图标
  - 用途：上传或编辑头像

### Email

- 标签：Email
- 输入框占位文案：Enter email
- 右侧图标：上下箭头
- 含义：字段排序 / 移动字段位置

### Phone

- 标签：Phone
- 输入框占位文案：Enter Phone
- 右侧图标：上下箭头
- 含义：字段排序 / 移动字段位置

### Location

- 标签：Location
- 输入框占位文案：City, Country
- 右侧图标：上下箭头
- 含义：字段排序 / 移动字段位置

## Add details 附加信息

- 分区标题：Add details
- 展示为一组可添加字段的圆角按钮
- 按钮通用样式：浅灰背景，左侧加号图标，灰色文字

可见附加字段按钮：

- LinkedIn
- Website
- Nationality
- Date of Birth
- Visa
- Passport or Id
- Availability
- Show More

## Show More 按钮

- 文案：Show More
- 样式：白色背景，深紫色文字，描边圆角按钮
- 用途：展开更多可添加字段

## 底部确认区

- 位置：固定在页面底部
- 背景：白色
- 上方有圆角边界 / 浅色分隔
- 主按钮：
  - 文案：Done
  - 图标：对勾
  - 样式：粉色到红粉色渐变，大尺寸圆角按钮，白色文字

## 可见交互元素

- Get Tips 提示入口
- Photo 头像上传区域
- Full name 输入框
- Professional title 输入框
- Email 输入框
- Phone 输入框
- Location 输入框
- Email / Phone / Location 字段排序按钮
- Add details 各附加字段按钮
- Show More 展开按钮
- Done 完成按钮
