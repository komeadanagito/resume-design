# Page 1 预览编辑页：Awards 奖项

## 页面状态

- 触发路径：点击 `Add Content 添加内容` 后，选择 `Awards 奖项`
- 当前界面：预览编辑页 / Edit Entry 编辑条目
- 编辑对象：Award / 奖项
- 页面用途：新增或编辑简历中的奖项名称、发行人、日期和奖项描述
- 布局：上方编辑卡片 + 下方固定确认区域
- 主色：深紫色标题文字，紫色工具栏选中态，粉色渐变确认按钮
- 语言：中英双语

## 编辑卡片

- 样式：白色大圆角卡片，轻微阴影
- 背景：页面底色为浅米灰色
- 卡片内部包含：
  - 标题区
  - 奖项基础信息表单
  - Date 日期选择区
  - Description 描述富文本编辑器

## 顶部区域

- 页面标题：Edit Entry 编辑条目
  - 位置：左上
  - 样式：大号深紫色粗体
- 提示入口：Get 得到Tips 尖端
  - 位置：右上偏中
  - 图标：灯泡
  - 样式：深色文字
- 预览按钮：
  - 位置：右上
  - 图标：眼睛
  - 样式：浅灰圆角图标按钮
- 删除按钮：
  - 位置：预览按钮右侧
  - 图标：垃圾桶
  - 样式：浅灰圆角图标按钮

## 表单字段

### Award 奖

- 标签：Award 奖
- 输入框占位文案：Enter award
- 样式：浅灰色圆角输入框
- 右侧按钮：
  - 文案：Link 关联
  - 图标：链条
  - 样式：白色描边圆角按钮
  - 用途：添加奖项相关链接

### Issuer 发行人

- 标签：Issuer 发行人
- 输入框占位文案：Enter Issuer
- 样式：浅灰色圆角输入框

### Date 日期

- 标签：Date 日期
- 输入类型：三个并列下拉选择器
- 下拉项：
  - Day 天
  - Month 月
  - Year 年
- 每个下拉框右侧都有向下箭头
- 样式：浅灰色圆角输入框

### 日期显示控制

- Day 天下方有复选框：
  - 文案：Don't show 不要显示
  - 用途：隐藏日期中的天
- Month 月下方有复选框：
  - 文案：Don't show 不要显示
  - 用途：隐藏日期中的月份

### Description 描述

- 标签：Description 描述
- 输入类型：富文本编辑器
- 占位文案：Describe your award... 请描述一下您获得的奖项......
- 编辑区域样式：
  - 浅灰色背景
  - 圆角矩形
  - 顶部工具栏与正文区域之间有分割线
  - 正文区域高度较大，适合输入奖项描述

## 富文本工具栏

工具栏位于 Description 描述编辑器顶部，从左到右：

- Bold 加粗
  - 图标：B
- Italic 斜体
  - 图标：I
- Underline 下划线
  - 图标：U
- 项目符号 / 列表
  - 图标：列表
- 插入链接
  - 图标：链条
- 左对齐
  - 图标：左对齐
  - 当前状态：选中
  - 选中样式：紫色背景，白色图标
- 居中对齐
  - 图标：居中对齐
- 右对齐
  - 图标：右对齐
- 两端对齐
  - 图标：多条横线

## 底部确认区

- 位置：页面底部独立白色卡片 / 固定底栏
- 样式：白色背景，大圆角，上方与编辑卡片分离
- 主按钮：
  - 文案：Done 完毕
  - 图标：对勾
  - 样式：粉色到红粉色渐变，大尺寸圆角按钮，白色文字
