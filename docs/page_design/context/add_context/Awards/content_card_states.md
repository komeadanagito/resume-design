# Page 1 内容卡片状态：Awards 奖项

## 页面状态

- 所属模块：Awards 奖项

- 展示形式：白色圆角内容卡片
- 语言：中英双语
- 状态类型：

- 卡片为单行高度

  - 颜色：深紫色
- 标题：
  - 文案：Awards 奖项
  - 样式：深紫色粗体大字
- 右侧展开按钮：
  - 图标：向下箭头
  - 含义：点击展开卡片

### 可见交互元素

- 整张 Awards 奖项卡片
- 右侧向下箭头展开按钮
