# Page 1 预览编辑页：Skills 技能

## 页面状态

- 触发路径：点击 `Add Content 添加内容` 后，选择 `Skills 技能`
- 当前界面：预览编辑页 / Edit Entry
- 编辑对象：Skill / 技能
- 页面用途：新增或编辑简历中的技能名称、技能说明 / 子技能，以及技能等级
- 布局：上方编辑卡片 + 下方固定确认区域
- 主色：深紫色标题文字，紫色工具栏选中态，粉色渐变确认按钮

## 编辑卡片

- 样式：白色大圆角卡片，轻微阴影
- 背景：页面底色为浅米灰色
- 卡片内部包含：
  - 标题区
  - 技能名称输入框
  - 信息 / 子技能富文本编辑器
  - 技能等级下拉选择器

## 顶部区域

- 页面标题：Edit Entry
  - 位置：左上
  - 样式：大号深紫色粗体
- 提示入口：Get Tips
  - 位置：右上偏中
  - 图标：灯泡
  - 样式：深色文字
- 预览按钮：
  - 位置：右上
  - 图标：眼睛
  - 样式：浅灰圆角图标按钮
- 删除按钮：
  - 位置：预览按钮右侧
  - 图标：垃圾桶
  - 样式：浅灰圆角图标按钮

## 表单字段

### Skill

- 标签：Skill
- 输入框占位文案：Enter Skill
- 样式：浅灰色圆角输入框

### Information / Sub-skills

- 标签：Information / Sub-skills
- 输入类型：富文本编辑器
- 占位文案：Enter information or sub-skills
- 编辑区域样式：
  - 浅灰色背景
  - 圆角矩形
  - 顶部工具栏与正文区域之间有分割线
  - 正文区域适合输入技能说明、关键词或子技能列表

### Skill level

- 标签：Skill level
- 输入类型：下拉选择器
- 占位文案：Select skill level
- 右侧图标：向下箭头
- 样式：浅灰色圆角输入框
- 用途：选择技能熟练度等级
