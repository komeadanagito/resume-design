## Icon Style 图标样式

### 标签

- 文案：Icon Style 图标样式
- 样式：深紫色，14px，bold

### 选项

- 控件类型：横排 8 个图标样式缩略图
- 间距：4px
- 每个缩略图展示同一个图标（链接/Link 图标 🔗）的不同样式变体

#### 单个图标缩略图样式

- 尺寸：约 44px × 44px
- 圆角：12px
- 未选中：白色/透明背景，浅灰边框
- 选中：浅品牌色背景（brand-50），品牌色边框

#### 8 种图标样式（从左到右）

1. **浅色背景 + 描线图标（选中）**：浅品牌色圆角方块背景 + 品牌色描线图标
2. **深灰背景 + 白色图标**：深灰圆形背景 + 白色描线图标
3. **灰色背景 + 白色图标**：中灰圆角方块背景 + 白色图标
4. **品牌色背景 + 白色图标**：品牌色圆角方块背景 + 白色图标
5. **深色背景 + 白色图标**：深色/黑色圆角方块 + 白色图标
6. **纯描线图标**：无背景，浅灰描线图标
7. **浅色描边图标**：无背景填充，浅色描边圆形 + 描线图标
8. **极浅描线图标**：无背景，极浅灰描线图标

## Advanced Settings 高级设置

- 位置：面板底部
- 文案：Advanced Settings 高级设置
- 右侧图标：下拉箭头（ChevronDown）
- 样式：灰色文字（ink-500），14px
- 交互：点击展开/收起高级设置区域
- 展开内容（规划）：
  - 页眉背景色设置
  - 页眉分隔线开关
  - 自定义间距调整

---

## 交互行为

- 切换 Text Alignment → 页眉文字对齐方式立即更新
- 切换 Details Arrangement → 联系信息排列方式立即更新
- 切换分隔符类型 → 联系信息之间的分隔符样式立即更新
- 切换 Icon Style → 联系信息图标视觉样式立即更新
- 所有更改实时反映到右侧预览
