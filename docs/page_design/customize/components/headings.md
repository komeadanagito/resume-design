## Style 标题样式

### 标签

- 文案：Style 样式
- 样式：深紫色，14px，bold

### 样式预设网格

- 布局：2 行 × 4 列网格
- 卡片间距：8px（gap-2）
- 共 8 个样式预设

#### 单个预设卡片样式

- 尺寸：等宽，高度约 56px
- 圆角：12px
- 未选中：白色背景，浅灰边框（surface-tag）
- 选中：浅品牌色背景（brand-50），品牌色边框（brand-500）
- 悬停：浅灰背景

#### 预设选项（从左到右，从上到下）

##### 第一行

1. **下划线（选中）**：短粗品牌色横线在上 + 细品牌色下划线，模拟 "标题 + 下划线" 样式。选中态。
2. **方框/背景色块**：灰色短横线包裹在浅灰方框内，模拟 "标题带背景色块"
3. **居中下划线**：灰色短横线居中 + 下方细灰色线
4. **全宽下划线**：灰色短横线左对齐 + 下方全宽细灰色线

##### 第二行

5. **小号左对齐**：短灰色横线左对齐，无装饰
6. **粗短横线**：短粗灰色横线左偏
7. **居中细线+横线**：灰色细横线居中，下方有短线段
8. **波浪/锯齿线**：灰色短横线 + 下方锯齿/波浪装饰线

### 选中行为

- 点击卡片切换选中
- 选中卡片：浅品牌色背景 + 品牌色边框 + 内部线条变品牌色
- 未选中：灰色线条
