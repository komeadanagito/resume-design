## Entry Layout 条目布局预设

### 布局

- 垂直排列 4 个可选布局卡片
- 每张卡片为横向缩略图，展示不同的条目排版方式
- 卡片间距：8px（gap-2）

### 单个卡片样式

- 宽度：满宽
- 高度：约 48px
- 圆角：12px
- 未选中：浅灰背景（surface-muted），灰色边框（surface-tag）
- 选中：浅品牌色背景（brand-50 / `#EBF3FF`），品牌色边框（brand-500 / `#0066FF`）

### 布局选项（从上到下）

#### 选项 1（当前选中）

- 缩略图内容：左侧为多条品牌色粗横线（代表标题/正文），右侧为日历图标 + 定位图标
- 含义：标题和描述在左，日期和地点在右上角

#### 选项 2

- 缩略图内容：左侧为日历图标 + 定位图标，右侧为多条灰色横线
- 含义：日期和地点在左，标题和描述在右

#### 选项 3

- 缩略图内容：左侧日历图标，中间为灰色横线，右侧定位图标
- 含义：日期在左侧列，内容居中，地点在右

#### 选项 4

- 缩略图内容：单条长灰色横线居中
- 含义：紧凑/单行布局

### 选中行为

- 点击卡片切换选中态
- 选中卡片：浅品牌色背景 + 品牌色边框 + 内部图标/线条变为品牌色
- 未选中卡片：灰色图标/线条

## 通用药丸按钮组（Pill Button Group）样式规范

此面板大量使用药丸按钮组，统一样式如下：

- 按钮形状：药丸（rounded-pill / 999px）
- 未选中：
  - 背景：白色 / 透明
  - 文字色：灰色（ink-500）
  - 边框：1px，浅灰色（surface-tag / `#F0ECE7`）

  - 背景：浅品牌色（brand-50 / `#EBF3FF`）
  - 文字色：品牌色（brand-500 / `#0066FF`）

- 文字：14px，semibold
- 过渡动画：transition
