# Font Size 字号

## 组件概览

- 组件名称：FontSizePanel
- 所属面板：Font Size 字号（侧边导航第 4 项）
- 容器样式：白色圆角卡片，轻微阴影
- 内边距：24px（p-6）

## 标题区

- 文案：Font Size 字号
- 样式：深紫色，18px，extrabold

## 控件模式：步进滑块 SteppedSlider

所有字号控件共用同一种 UI 模式：**步进滑块 + 加减按钮**。

### 通用步进滑块样式

- 布局：每个控件占一行，包含标签行 + 滑块行
- 标签行：
  - 左侧：字段名称（深紫色，14px，bold）
  - 右侧：当前数值（深紫色，14px），格式如 `10.5pt`、`+11pt`、`+3pt`、`+0pt`
- 滑块行（标签下方）：
  - 左侧：步进滑块轨道
  - 右侧：加减按钮组

### 步进滑块轨道

- 容器：
  - 背景：浅灰（`surface-muted` / `#F8F6F3`）
  - 圆角：8px（rounded-lg）
  - 高度：约 40px
  - 宽度：占满可用空间（减去加减按钮宽度）
- 分段：
  - 轨道内等分为 **9 个格子**（由竖向分隔线划分）
  - 分隔线：1px 宽，浅灰色（`surface-tag` / `#F0ECE7`），高度约 60%居中
- 活动滑块（Thumb）：
  - 形状：方形/圆角小方块
  - 尺寸：约 36px × 36px
  - 背景色：品牌色（`brand-500` / `#0066FF`）
  - 圆角：6px
  - 位置：当前选中格子
  - 无拖拽手柄，整个色块即为活动指示器

### 加减按钮组

- 位置：滑块轨道右侧
- 布局：横排 2 个按钮，间距 4px
- 单个按钮样式：
  - 尺寸：约 40px × 40px
  - 背景：白色（surface-card）
  - 边框：1px，浅灰色（`surface-tag`）
  - 圆角：10px
  - 文字：品牌色/深紫色，18px，semibold
  - 符号：`−`（减号）和 `+`（加号）
  - 悬停：背景变浅灰

## 字号字段列表

字段间距：24px（gap-6），垂直排列。

### Base Font Size 基础字号

- 标签：Base Font Size 基础字号
- 数值显示：`10.5pt`（当前值）
- 滑块位置：第 3 格（从左数，0-indexed 为 2）
- 步进范围：8pt ~ 14pt，步长 0.5pt
- 影响：简历正文基础字号

### Full Name 姓名字号

- 标签：Full Name 姓名
- 数值显示：`+11pt`（相对于基础字号的偏移）
- 滑块位置：第 4 格
- 步进范围：+0pt ~ +20pt，步长约 1~2pt
- 影响：简历顶部姓名的字号

### Section Headings 章节标题字号

- 标签：Section Headings 章节标题
- 数值显示：`+3pt`
- 滑块位置：第 4 格（中间偏左）
- 步进范围：+0pt ~ +10pt
- 影响：各模块标题（如 Experience、Education 等）的字号

### Entry Header 条目标题字号

- 标签：Entry Header 条目标题
- 数值显示：`+0pt`
- 滑块位置：第 1 格（最左侧）
- 步进范围：+0pt ~ +8pt
- 影响：每个条目内的标题（如职位名、学校名）的字号

## 交互行为

- 点击滑块轨道上的某个格子 → 滑块跳到该位置，数值更新
- 点击 `+` 按钮 → 滑块右移一格，数值增加
- 点击 `−` 按钮 → 滑块左移一格，数值减少
- 到达最小值时 `−` 按钮禁用（opacity 降低）
- 到达最大值时 `+` 按钮禁用
- 数值变化实时反映到右侧简历预览
