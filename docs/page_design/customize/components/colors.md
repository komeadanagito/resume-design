# Colors 颜色

## 组件概览

- 组件名称：ColorsPanel
- 所属面板：Colors 颜色（侧边导航第 9 项）
- 容器样式：白色圆角卡片，轻微阴影
- 内边距：24px（p-6）
- 状态：✅ 基于截图

## 标题区

- 文案：Colors 颜色
- 样式：深紫色（ink-900），18px，extrabold

---

## Color Scope 颜色应用范围

### 选项

- 控件类型：横排 3 个可选缩略图卡片
- 间距：12px

#### Full Page（当前选中）

- 缩略图：浅品牌色矩形（模拟整页着色）
- 标签：Full Page 全页
- 选中样式：浅品牌色背景，品牌色边框

#### Header

- 缩略图：上方灰色色块 + 下方白色区域（模拟仅页眉着色）
- 标签：Header 页眉
- 未选中样式：白色背景，浅灰边框

#### Border

- 缩略图：白色中间区域 + 左侧灰色竖条边框（模拟侧边边框）
- 标签：Border 边框
- 未选中样式

---

## Color Mode 颜色模式

### 选项

- 控件类型：横排 3 个可选缩略图卡片
- 间距：12px

#### Single（当前选中）

- 缩略图：深色/黑色矩形，内有白色勾选标记 ✓
- 标签：Single 单色
- 选中样式：品牌色边框

#### Multi

- 缩略图：灰色矩形，内有文字排版图标 `I`
- 标签：Multi 多色
- 未选中样式

#### Image

- 缩略图：灰色矩形，内有纹理/图案预览（如叶子纹理）
- 标签：Image 图片
- 未选中样式

## Color Palette 调色板

### 布局

- 2 行圆形色块网格
- 第一行：9 个色块
- 第二行：7 个色块
- 色块间距：8px
- 单个色块尺寸：40px × 40px，圆形

### 色块列表

#### 第一行（从左到右）

1. **无色/取消**：白色背景 + 对角线斜杠图标（⊘），表示去除颜色
2. 深灰绿（`#2F4F4F` 附近）
3. 灰绿（`#4A6B6B` 附近）
4. 浅蓝灰（`#A8C8C8` 附近）
5. 青绿（`#3D8B8B` 附近）
6. 深蓝绿（`#1B4D5A` 附近）
7. 蓝（`#3366CC` 附近）
8. 天蓝（`#5B9BD5` 附近）
9. 品蓝（`#6B9FD6` 附近）

#### 第二行（从左到右）

10. 天蓝浅（`#7BC8F6` 附近）
11. 深紫（`#2D0063` 附近）
12. 紫红（`#5B2C4D` 附近）
13. 灰粉（`#B88B9C` 附近）
14. 玫红（`#D66B8D` 附近）
15. 粉红（`#E8707D` 附近）
16. **彩虹/自定义**：渐变彩虹圆形，点击打开颜色拾取器

### 色块交互

- 点击色块 → 应用该颜色为强调色
- 选中色块：外环品牌色描边（2px），或内部勾选标记
- 悬停：略微放大 + 轻微阴影
- 彩虹色块：点击弹出完整颜色拾取器（色轮/色板 + 十六进制输入）

## Apply Accent Color 应用强调色

### 标签

- 文案：Apply Accent Color 应用强调色
- 样式：深紫色，14px，bold

### 复选框列表

- 布局：2 列网格，每列约 50% 宽度
- 每行一个复选框 + 标签文字
- 行间距：12px

#### 复选框样式

- 尺寸：22px × 22px
- 圆角：6px
- 未勾选：白色背景，浅灰边框
- 勾选：品牌色背景（brand-500），白色勾选标记 ✓
- 标签文字：深色（ink-900），14px

## 交互行为

- 切换 Color Scope → 颜色应用到全页 / 仅页眉 / 仅边框
- 切换 Color Mode → Single（单色主题）/ Multi（多色搭配）/ Image（背景图案）
- 点击色块 → 即时更新强调色，所有已勾选的元素颜色跟随变化
- 勾选/取消 Apply Accent Color → 对应元素使用/不使用强调色
- 所有更改实时反映到右侧预览
