# Layout 布局

## 组件概览

- 组件名称：LayoutPanel
- 所属面板：Layout 布局（侧边导航第 3 项）
- 容器样式：白色圆角卡片，轻微阴影
- 内边距：24px（p-6）

## 标题区

- 文案：Layout 布局
- 样式：深紫色，18px，extrabold
- 右侧附带撤销/重做按钮（在 Document 面板中可见）

## Columns 列数选择

### 标签

- 文案：Columns 列数
- 样式：深紫色，14px，bold
- 下方间距：12px

### 选项卡

布局：横排 3 个可选卡片，等宽排列，间距 12px

#### One 单列（当前选中）

- 缩略图：
  - 尺寸：约 120px × 80px
  - 选中样式：浅蓝/浅品牌色背景（`brand-50` / `#EBF3FF`），品牌色边框（`brand-500` / `#0066FF`）
  - 圆角：12px
  - 内容图示：3 条等宽紫色横线居中排列，代表单列布局
  - 横线颜色：品牌色（`#0066FF`），选中态
- 标签文字：One
  - 位置：卡片下方居中
  - 样式：深色，14px
  - 选中态：深紫色粗体

#### Two 双列

- 缩略图：
  - 未选中样式：浅灰背景（`surface-muted`），灰色边框
  - 内容图示：左右两组灰色横线，左侧 3 条满宽 + 右侧 3 条满宽，模拟双列布局
  - 横线颜色：灰色（`ink-300`）
- 标签文字：Two
  - 样式：灰色，未选中态

#### Mix 混合

- 缩略图：
  - 未选中样式：同 Two
  - 内容图示：左侧 3 条窄横线 + 右侧 2 条宽横线，模拟侧边栏+主内容混合布局
  - 横线颜色：灰色（`ink-300`）
- 标签文字：Mix
  - 样式：灰色，未选中态

### 选中行为

- 点击卡片切换选中态
- 选中卡片边框变为品牌色，背景变为浅品牌色
- 缩略图内横线颜色从灰色变为品牌色
- 对应更新全局布局设置

## Change Section Layout 更改模块布局

### 标签

- 文案：Change Section Layout 更改模块布局
- 样式：深紫色，14px，bold
- 下方间距：8px

### 空状态提示

- 文案：You don't have any sections to rearrange yet 📝
  - 中文：你还没有可以重新排列的模块
- 样式：灰色（ink-500），14px
- 末尾 emoji：📝

### 有内容状态（规划）

- 展示当前简历所有模块
- 每个模块可拖拽到左栏或右栏（双列/混合模式时）
- 双栏拖拽区域可视化
- 拖拽手柄图标

## 交互行为

- 切换列数 → 实时更新右侧简历预览
- Change Section Layout 区域在有模块时，展示拖拽排序界面
- 撤销/重做按钮记录布局变更历史
