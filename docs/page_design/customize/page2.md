## 子导航各面板功能说明

以下为点击左侧子导航不同项后应展示的面板内容。当前截图仅展示了 Document 面板，其余面板为功能规划。

### Templates 模板面板

- 面板标题：Templates 模板
- 功能：展示所有可用简历模板的网格/列表
- 每个模板项：
  - 缩略图预览
  - 模板名称
  - 选中指示（当前使用的模板高亮）
- 操作：点击模板直接应用到当前简历

### Layout 布局面板

- 面板标题：Layout 布局
- 功能：调整简历整体布局结构
- 布局选项：
  - 列数选择：单列 / 双列
  - 侧栏位置：左侧栏 / 右侧栏
  - 页眉布局样式选择
- 撤销/重做按钮
- 布局预览缩略图

### Font Size 字号面板

- 面板标题：Font Size 字号
- 功能：调整简历中各部分字号
- 控件：
  - 整体字号：滑块或数值输入（如 Small / Medium / Large）
  - 标题字号调整
  - 正文字号调整
  - 辅助文字字号调整

### Spacing 间距面板

- 面板标题：Spacing 间距
- 功能：调整简历中各元素之间的间距
- 控件：
  - 行间距：滑块控件
  - 段落间距：滑块控件
  - 模块间距：滑块控件
  - 页边距：上/下/左/右数值输入

### Entries 条目面板

- 面板标题：Entries 条目
- 功能：控制简历条目的展示样式
- 选项：
  - 日期位置：左侧 / 右侧 / 下方
  - 条目分隔线：显示 / 隐藏
  - 条目布局样式选择（多种预设排版）

### Headings 标题面板

- 面板标题：Headings 标题
- 功能：控制各区块标题的样式
- 选项：
  - 标题大小写：正常 / 全大写
  - 标题对齐：左对齐 / 居中
  - 标题装饰：无 / 下划线 / 背景色块
  - 标题图标：显示 / 隐藏
  - 标题颜色：跟随主题 / 自定义

### Font 字体面板

- 面板标题：Font 字体
- 功能：选择简历使用的字体家族
- 控件：
  - 标题字体选择器（下拉或字体列表）
  - 正文字体选择器
  - 字体预览效果

### Colors 颜色面板

- 面板标题：Colors 颜色
- 功能：设置简历配色方案
- 控件：
  - 预设配色方案选择（多组色板）
  - 主色/强调色：颜色选择器
  - 标题颜色：颜色选择器
  - 正文颜色：颜色选择器
  - 背景颜色：颜色选择器
  - 链接颜色：颜色选择器

### Header 页眉面板

- 面板标题：Header 页眉
- 功能：控制简历页眉区域的布局和样式
- 选项：
  - 页眉布局：多种预设样式（居中 / 左对齐 / 分栏）
  - 姓名位置
  - 联系信息排列方式：单行 / 多行 / 图标+文字
  - 页眉背景色
  - 页眉分隔线：显示 / 隐藏

### Photo 照片面板

- 面板标题：Photo 照片
- 功能：控制头像照片的显示方式
- 选项：
  - 显示照片：开关控件
  - 照片形状：圆形 / 方形 / 圆角方形
  - 照片尺寸：滑块控件
  - 照片位置：页眉内 / 侧栏顶部
  - 照片边框：无 / 细线 / 阴影

### Links 链接面板

- 面板标题：Links 链接
- 功能：控制简历中链接的展示方式
- 选项：
  - 链接颜色：颜色选择器
  - 链接样式：下划线 / 无装饰
  - 链接图标：显示 / 隐藏
  - URL 显示：完整URL / 显示文字 / 隐藏URL

### Footer 页脚面板

- 面板标题：Footer 页脚
- 功能：控制简历页脚内容和样式
- 选项：
  - 显示页脚：开关控件
  - 页码：显示 / 隐藏
  - 页脚文字：自定义输入
  - 页脚对齐：左 / 中 / 右
  - 页脚分隔线：显示 / 隐藏

### Sections 模块面板

- 面板标题：Sections 模块
- 功能：管理简历各模块的显示顺序和可见性
- 控件：
  - 模块列表：拖拽排序
  - 每个模块项：
    - 模块名称
    - 可见性开关
    - 拖拽手柄
  - 分栏分配：将模块指定到主栏或侧栏（双列布局时）
