# 工作台 1 — 简历编辑

> 主要用于简历编辑。

## 核心逻辑

**左边填 → 中间看 → 右边 AI**

```
┌──────────┬────────────────────┬─────────────┐
│ 左侧编辑 │     中间预览        │ 右侧 AI 区  │
└──────────┴────────────────────┴─────────────┘
```
